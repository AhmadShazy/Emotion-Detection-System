# Minimal dependency set for the TEXT-ONLY deployment.
#
# Serves /analyze/text and /mock/* — everything the LLM team needs to build
# against. No microphone, no camera, no OpenFace, so it runs on ordinary Linux
# hosting.
#
# Install with the CPU torch index, or pip pulls ~2 GB of CUDA libraries that
# would never be used:
#
#   pip install --extra-index-url https://download.pytorch.org/whl/cpu \
#               -r requirements-text.txt
#
# ─────────────────────────────────────────────────────────────────────────────
# This list was derived empirically, not guessed. Each candidate package was
# simulated as absent and the text path re-tested. Omitting any line below
# makes RoBERTa fail to load — and the failure is SILENT: the server still
# starts, /health still returns 200, and every request comes back "neutral".
# That is much worse than a crash, so do not trim this list without re-testing.
# ─────────────────────────────────────────────────────────────────────────────

# ── Core ML ──────────────────────────────────────────────────────────────────
torch
transformers

# Required by transformers to construct the text-classification pipeline.
# torchaudio in particular looks unrelated to text and is not: without it the
# pipeline factory raises during import and RoBERTa never loads.
torchaudio
scipy
pandas
soundfile
numpy

# ── Web ──────────────────────────────────────────────────────────────────────
fastapi
uvicorn[standard]
python-multipart
python-dotenv
httpx

# ─────────────────────────────────────────────────────────────────────────────
# Deliberately EXCLUDED — verified unused on the text path, and the heaviest
# things in the full requirements. Re-add them when full mode is deployable:
#   speechbrain       speech emotion recognition
#   openai-whisper    batch speech-to-text (also needs the ffmpeg binary)
#   faster-whisper    streaming speech-to-text
#   sounddevice       microphone capture (needs an actual audio device)
